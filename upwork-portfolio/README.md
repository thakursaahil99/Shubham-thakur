# Upwork Portfolio Kit — copy-paste ready

Pictures are in the `images/` folder (1600×900 JPG, which Upwork accepts). Use these as the project **cover/thumbnail**.
Real page screenshots taken from the live sites (1600×1000 PNG) are in `screenshots/<project>/`:
`01-home.png` plus up to 3 inner pages (About, Services, Contact…). On Upwork, under **Add content → Image**,
upload the cover first, then these screenshots, one after another, all in the same project.
**Rule:** only add a project you actually worked on, and change the role/description if needed.
On Upwork, getting caught with work that isn't yours can get your account restricted.

---

## Upwork pe ek project kaise add karein (step by step)

1. Profile page → **Portfolio** section → green **+** button (top right).
2. **Project title** → copy the "Title" below (max 70 characters).
3. **Your role** (optional) → copy the "Role" below.
4. **Project description** → copy the "Description" below (max 600 characters).
5. **Skills and deliverables** → type the "Skills" below one by one and pick each from the dropdown (max 5).
6. **Add content** → **Image** → upload the matching file from `images/`.
   Then **Link** → paste the live site URL.
7. Click **Next: Preview** → check it → **Publish**.
   (To save without publishing, use **Save as draft**; it goes to the Drafts tab.)

Tip: 6–8 strong projects are better than 50 weak ones. The first 3–4 appear in the profile preview, so add your best work first.
